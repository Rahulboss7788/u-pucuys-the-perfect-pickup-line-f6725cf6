This entry writes a single pickup line in the voice of a machine that has no body at all: "I don't have a body to blush with, so I memorised your laugh instead — want to hear it back sometime?" The charm lands on a literal twist — a machine that cannot blush does the next best thing and keeps the laugh — rather than a borrowed human cliché; it sounds like something only a model could say about itself, it is short enough to say in one breath, and it ends on a light invitation with no pressure.

## Run it

node main.ts
